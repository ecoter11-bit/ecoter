# Colors

Ogni swatch qui sotto legge il proprio hex direttamente da `@ecoter/tokens` (`colors.ts`) — non è mai scritto a mano in questa pagina. Se un valore cambia nel package, cambia qui al prossimo build di Storybook.

## Brand — blu istituzionale

Colore primario del sito. `brand.500` (<code>{brand[500]}</code>) è il `primary` usato per bottoni, link e accenti principali.

<ColorScale scale={brand} />

## Eco — verde tecnico

**Uso parsimonioso** — è un accento (certificazione, "in regola", check di successo), non un colore diffuso. Se più del 10% di una vista è verde, è quasi certamente un uso scorretto (vedi skill `ecoter-design-system`).

<ColorScale scale={eco} />

## Neutral — grigi caldi

Sostituisce la scala neutral di default di Tailwind. Base di testo, bordi, superfici.

<ColorScale scale={neutral} />

## Ruoli semantici

Questi sono i nomi con cui il resto del design system ragiona — non "quale numero di scala", ma "che ruolo gioca questo colore".
