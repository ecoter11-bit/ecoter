# content/raw

Documenti sorgente originali forniti dal cliente (Word, PowerPoint, PDF, Excel).

**Non modificare questi file.** Sono la fonte di verità da cui vengono estratti i contenuti.

## Processo di importazione

1. Caricare qui i documenti originali (es. `catalogo-corsi-2025.docx`, `presentazione-rspp.pptx`)
2. Eseguire lo script di estrazione: `npm run import:raw`
3. I dati estratti vengono salvati in `content/generated/` in formato JSON intermedio
4. Il team editoriale revisionerà e convertirà i JSON in file MDX finali in `content/courses/`
